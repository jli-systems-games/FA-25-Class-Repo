# 拓麻歌子游戏 - 快速开始

## 🎮 操作方法
- **空格** = 打开菜单 / 确认选择
- **↑ ↓** = 选择菜单选项
- **← →** = 关闭菜单

## ⚡ 5分钟快速设置

### 1️⃣ 创建场景结构
```
Canvas (320x480)
├─ Background (Image, 淡绿色)
├─ PetDisplay (Image, 白色)
│  └─ PetImage (Image, 128x128)
├─ HungerText (Text: "饥饿: 100")
├─ HappinessText (Text: "快乐: 100")
├─ HealthText (Text: "健康: 100")
├─ AgeText (Text: "年龄: 0岁")
├─ StatusText (Text: "欢迎!")
└─ MenuPanel (Panel)
   ├─ MenuOption0 (Text: "喂食")
   ├─ MenuOption1 (Text: "玩耍")
   ├─ MenuOption2 (Text: "治疗")
   ├─ MenuOption3 (Text: "清洁")
   ├─ MenuOption4 (Text: "睡觉")
   └─ MenuOption5 (Text: "状态")
```

### 2️⃣ 添加脚本
创建空物体 "GameController"，添加：
- TamagotchiGame.cs
- TamagotchiSetup.cs

### 3️⃣ 连接引用
在 Inspector 中将所有 UI 元素拖到对应的脚本字段

### 4️⃣ 点击 Play！

## 📊 游戏机制速查

| 属性 | 变化速度 | 影响 |
|------|----------|------|
| 饥饿 | -10/30秒 | <20时健康-5 |
| 快乐 | -10/45秒 | <20时健康-3 |
| 健康 | 受多种因素影响 | =0时死亡 |
| 年龄 | +1/60秒 | 触发进化 |

## 🐣 成长阶段
- 蛋 → 婴儿 (孵化10秒)
- 婴儿 → 儿童 (3岁)
- 儿童 → 成年 (7岁)

## 🎯 菜单功能
1. **喂食**: 饥饿+30, 快乐+10
2. **玩耍**: 快乐+30, 饥饿-10
3. **治疗**: 治愈疾病, 健康+30
4. **清洁**: 清除便便, 快乐+20
5. **睡觉**: 属性下降速度减半
6. **状态**: 查看详细信息

## ⚠️ 注意事项
- 每120秒产生1个便便
- 3个以上便便会生病
- 低饥饿/快乐度可能生病
- 健康归零 = 游戏结束
