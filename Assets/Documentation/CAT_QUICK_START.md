# 🐱 猫咪拓麻歌子 - 快速开始指南

## 🎮 游戏介绍

这是一个经典拓麻歌子风格的猫咪养成游戏！完全复刻了原版的黑白像素艺术风格。

### 猫咪成长阶段
```
🥚 蛋 → 🐱 小猫 → 😺 少年猫 → 😻 成年猫
(10秒)   (0-2岁)   (3-6岁)    (7岁+)
```

## ⚡ 5分钟快速设置

### 1️⃣ 创建Unity场景

#### Canvas设置
```
Canvas Scaler:
- UI Scale Mode: Scale With Screen Size
- Reference Resolution: 320 x 480
- Match: 0.5
```

#### 背景色
```
Camera Background: #C8E6C9 (经典拓麻歌子绿)
或者添加背景Image，颜色设为淡绿色
```

### 2️⃣ UI结构
```
Canvas
├─ Background (Image, 淡绿色 #C8E6C9)
├─ PetDisplay (Image, 浅灰色边框)
│  └─ PetImage (Image, 128x128)
├─ HungerText (Text: "🍖 饥饿: 100")
├─ HappinessText (Text: "😊 快乐: 100")
├─ HealthText (Text: "❤️ 健康: 100")
├─ AgeText (Text: "📅 年龄: 0岁")
├─ StatusText (Text: "欢迎养猫!")
└─ MenuPanel (Panel)
   ├─ MenuOption0 (Text: "喂食 🍖")
   ├─ MenuOption1 (Text: "玩耍 🎾")
   ├─ MenuOption2 (Text: "治疗 💊")
   ├─ MenuOption3 (Text: "清洁 🧹")
   ├─ MenuOption4 (Text: "睡觉 😴")
   └─ MenuOption5 (Text: "状态 📊")
```

### 3️⃣ 添加脚本

创建空物体 `GameController`，添加3个脚本：
1. **TamagotchiGame.cs** (主逻辑)
2. **CatSpriteGenerator.cs** (猫精灵生成)
3. **CatTamagotchiSetup.cs** (初始化)

### 4️⃣ 连接引用

在 `CatTamagotchiSetup` 组件中：
- Game Controller → 拖入TamagotchiGame组件

在 `TamagotchiGame` 组件中连接所有UI元素

### 5️⃣ 运行！

点击Play，10秒后蛋会孵化成可爱的小猫咪！ 🐱

## 😺 猫咪互动功能

### 1. 🍖 喂食
- 投喂小鱼或猫粮
- 饥饿度 +30
- 快乐度 +10
- 动画：猫咪吃鱼

### 2. 🎾 玩耍
- 用逗猫棒或毛线球
- 快乐度 +30
- 饥饿度 -10（玩耍消耗体力）
- 动画：猫咪跳跃

### 3. 💊 治疗
- 生病时使用
- 治愈疾病
- 健康度 +30

### 4. 🧹 清洁
- 清理猫砂盆
- 移除便便
- 快乐度 +20
- 可能治愈疾病

### 5. 😴 睡觉
- 让猫咪休息
- 属性下降速度减半
- 可切换

### 6. 📊 状态
- 查看详细信息
- 当前阶段
- 年龄、便便数量
- 健康状态

## 📊 猫咪状态说明

### 属性变化
```
饥饿度: 每30秒 -10  (小猫容易饿)
快乐度: 每45秒 -10  (猫咪需要陪伴)
健康度: 受多种因素影响
年龄:   每60秒 +1岁
```

### 成长时间表
```
🥚 蛋期    : 孵化 10秒
🐱 小猫期  : 0-2岁 (约2分钟)
😺 少年猫  : 3-6岁 (约4分钟)
😻 成年猫  : 7岁+ (最终形态)
```

## ⚠️ 注意事项

### 猫咪会生病如果：
- 饥饿度 < 10
- 快乐度 < 10
- 便便 ≥ 3个不清理

### 猫咪会死亡如果：
- 健康度 = 0
- 会变成天使猫 👼

### 便便系统
```
产生间隔: 每120秒1个
最多数量: 4个
影响:
 - 降低快乐度
 - 3个以上会生病
```

## 🔧 自定义选项

### 修改猫咪颜色
在 `CatSpriteGenerator.cs` 中修改：
```csharp
private static Color classicBlack = new Color(0.2f, 0.25f, 0.2f);
// 改成其他颜色，如橙猫：
private static Color classicOrange = new Color(1f, 0.6f, 0.2f);
```

### 调整难度
在 `TamagotchiGame.cs` 中修改：
```csharp
// 更容易（慢速下降）
private float hungerDecreaseInterval = 60f;  // 原30秒改为60秒
private float happinessDecreaseInterval = 90f; // 原45秒改为90秒

// 更困难（快速下降）
private float hungerDecreaseInterval = 20f;
private float happinessDecreaseInterval = 30f;
```

### 快速成长
```csharp
private float ageInterval = 10f; // 原60秒改为10秒，快速看到进化
```

## 🆘 常见问题

**Q: 猫咪不动了？**
A: 检查是否在睡觉状态，按空格→睡觉关闭

**Q: 看不到精灵？**
A: 确认CatTamagotchiSetup已正确执行，检查Console错误

**Q: 按键没反应？**
A: 确保Game窗口处于焦点状态

**Q: 猫咪太快死了？**
A: 调整难度参数，延长属性下降间隔

**Q: 想要不同颜色的猫？**
A: 修改 classicBlack 颜色值
