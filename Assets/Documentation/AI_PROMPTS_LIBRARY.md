```

- "professional game asset"
- "pixel perfect"
- "clean lines"
- "consistent style"
- "anti-aliasing for smooth edges" (for larger sprites)
- "dithering for shading" (for retro look)
```

### 控制风格的关键词
```
风格变体：
- "8-bit NES style" (8色限制)
- "16-bit SNES style" (更多颜色和细节)
- "Game Boy style" (4色绿色调)
- "Sega Genesis style" (鲜艳色彩)
- "modern pixel art" (高色彩，平滑)
```

### 避免常见问题
```
添加这些约束：
- "no blur" (避免模糊)
- "sharp pixels" (保持像素锐利)
- "transparent background, not white" (确保透明)
- "no watermark" (无水印)
- "single sprite, not multiple" (单个精灵)
- "centered in frame" (居中构图)
```

## 🎓 实战示例

### 示例1: 使用Bing Image Creator

**第1步：生成蛋精灵**
前往: bing.com/create
输入:
```
pixel art egg sprite for virtual pet game, white with pink spots, 
32x32 pixels, transparent background, cute kawaii style, simple shape, 
game asset, retro tamagotchi aesthetic
```

**第2步：生成婴儿精灵**
```
pixel art baby creature sprite, round pink blob, two dot eyes, small smile, 
32x32 pixels, transparent background, tamagotchi style, cute game character, 
minimal details, pastel pink color
```

**第3步：下载并清理**
1. 下载生成的图片
2. 在Paint.net或GIMP中打开
3. 裁剪到精确32x32像素
4. 确保背景透明
5. 另存为PNG

### 示例2: Leonardo.ai 工作流

**设置：**
1. 选择 "Pixel Art" 模型
2. Image Dimensions: 512x512
3. Number of Images: 4（获得更多选择）
4. Guidance Scale: 7-10（更严格遵循提示词）

**提示词：**
```
cute pixel art virtual pet sprite, multiple evolution stages shown, 
egg baby child adult, 32x32 pixels each, arranged horizontally, 
transparent background, consistent kawaii style, pastel colors, 
sprite sheet layout, game assets
```

**后处理：**
- 在Sprite Editor中分割
- 调整对比度
- 移除背景
- 统一尺寸
