## 📚 资源使用指南

### 许可证类型说明

```
📄 CC0 (公共域)
   ✓ 完全自由使用
   ✓ 商业用途OK
   ✓ 无需标注作者
   ✓ 可修改

📄 CC-BY 3.0/4.0
   ✓ 自由使用
   ✓ 商业用途OK
   ✓ 必须标注作者
   ✓ 可修改

📄 OFL (Open Font License)
   ✓ 字体专用许可
   ✓ 自由使用和修改
   ✓ 不能单独售卖字体
   ✓ 商业使用OK

📄 GPL (General Public License)
   ✓ 开源许可
   ✓ 必须开源衍生作品
   ⚠ 商业使用需注意
```
