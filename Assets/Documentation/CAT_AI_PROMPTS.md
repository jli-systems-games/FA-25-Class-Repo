## 💡 提示词技巧

### 获得单色效果
```
✓ 使用 "monochrome black and white"
✓ 添加 "1-bit pixel art"
✓ 指定 "no grayscale, no shading"
✓ 参考 "Game Boy original" 或 "LCD screen"
✗ 避免 "detailed", "realistic", "shaded"
```

### 保持像素锐利
```
✓ "pixel perfect"
✓ "no anti-aliasing"
✓ "sharp edges"
✓ "point filtering"
✗ 避免 "smooth", "blurred", "soft"
```

### 匹配拓麻歌子风格
```
✓ "tamagotchi style"
✓ "retro virtual pet aesthetic"
✓ "1996 LCD game"
✓ "minimal simple design"
✓ "iconic and recognizable"
```

```

□ 精灵尺寸准确（32x32）
□ 线条锐利，无模糊
```

**提示**：如果AI生成的图片有灰度或彩色，可以：
1. 在图像编辑器中转换为黑白
2. 使用阈值工具 (Threshold)
3. 调整提示词强调 "pure black and white only"
